# Git and GitHub Assignment
This is a simple Python project I made to learn how to use Git and GitHub for class.

## What this project does
It's a basic Python script (app.py) that prints out a couple of lines of text. The main goal of this assignment was practicing how to make branches, commit changes, and merge them using a Pull Request.

## How to run it
1. Clone the repository: git clone [https://github.com/sadias4237/git-github-assignment.git](https://github.com/sadias4237/git-github-assignment.git)
2. Go into the project folder: cd git-github-assignment
3. Run the script: python app.py
